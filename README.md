# 🏥 Hospital ERP System

A full-stack Hospital ERP (Enterprise Resource Planning) web application developed to manage hospital operations such as patients, doctors, appointments, medicines, prescriptions, billing, and medication reminders.

## 🚀 Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Bootstrap
- Axios

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST API

### Database
- MySQL

## ✨ Features

- Admin Dashboard
- Patient Management
- Doctor Management
- Unique login credentials for Doctors and Patients
- Role-based Patient and Doctor portals
- Appointment Booking System
- Doctor-specific appointment management
- Medicine Management
- Prescription Management
- Patient-specific prescriptions
- Billing Management
- Patient-specific billing records
- 💊 Medication Alarm / Reminder
- Medication alarm ON/OFF and Delete functionality

## 💊 Special Feature - Medication Alarm

Patients can set medication reminder times for their prescribed medicines.

The system displays a reminder when it is time to take the medicine while the Patient Portal is running.

## 📁 Project Structure

Hospital-ERP-FullStack/

- backend/ - Spring Boot Backend
- frontend/ - React Frontend
